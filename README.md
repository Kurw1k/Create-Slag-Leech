# Create: Slag Leech

**Create: Slag Leech** is an addon for the [Create](https://github.com/Creators-of-Create/Create) mod on **NeoForge (Minecraft 1.21.1)**. The mod introduces a custom semi-liquid mob — the **Slag Leech** — featuring an oily puddle aesthetic with internal mechanical shafts and metal components continuously rotating inside its body.

---

## ⚙️ Features
* **Custom Entity (`SlagLeechEntity`)**: A unique mob that seamlessly fits into the industrial atmosphere of the Create mod.
* **Dynamic Rendering (`SlagLeechRenderer`)**: Utilizes matrix transformations (`PoseStack`) to render actual shafts (`AllBlocks.SHAFT`) and items directly inside the entity's model in real-time.
* **Custom Model**: A low-profile flat puddle model designed in Blockbench.

---

## 🛠️ Requirements
* **Minecraft**: `1.21.1`
* **Loader**: `NeoForge`
* **Dependencies**: `Create` (1.21.1 version)
